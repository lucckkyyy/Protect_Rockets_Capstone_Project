# Protect Rockets Capstone Project

Protecting UToledo students from phishing and malicious links.

| Part | What it is | Folder |
|---|---|---|
| **Aware Rockets** | Game that teaches students to spot phishing (awareness) | [`/game`](game) |
| **Protect Rockets** | Tool that checks emails and links for threats (protection) | [`/tool`](tool) |
| **Website** | protectrockets.utoledo.edu, hosts the game link and tool download | [`/website`](website) |
| **Docs** | Report, slides, screenshots | [`/docs`](docs) |

## Team rules
- Only edit files in your own folder.
- Commit small and often, with clear messages.
- Never commit passwords or API keys (this repo is public). Use a `.env` file; it is git-ignored.

## Run the game
See [`game/README.md`](game/README.md). On Windows, install Python and double-click `game/run_game.bat`.
